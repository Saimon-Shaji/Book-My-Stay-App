# Book My Stay App

This project demonstrates the implementation of a Hotel Booking Management System using Core Java and Data Structures.

## Use Cases

* UC1: Application Entry & Welcome Message
* UC8: Palindrome Checker using Linked List
* UC9: Palindrome Checker using Recursion

## Technologies Used

* Java
* IntelliJ IDEA
* Git & GitHub

## How to Run

```bash
javac UseCase1HotelBookingApp.java
java UseCase1HotelBookingApp
```
